# Training

個人自用的推拉腿訓練、飲食、體重與增肌紀錄 App（GitHub Pages）。

- App：`index.html`（根目錄就是網站）
- 原始碼：`source/`（`python3 source/src/build.py` 產生網站檔案）
- 雲端程式：`source/server/Code.gs`（KEY 是空白佔位，實際密碼不放在這裡）

圖片來源：Everkinetic（CC BY-SA 4.0）、free-exercise-db（Unlicense）、Exercise data by RepDB（https://repdb.co ，坐姿蹬腿與坐姿提踵插畫）；肌肉圖：react-native-body-highlighter（MIT）。
